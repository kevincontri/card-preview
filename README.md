## Sobre o projeto

Card de preview de artigo com alternância entre tema claro e escuro, construído com HTML, CSS e JavaScript puros — sem frameworks ou dependências externas.

## Funcionalidades

- Alternância de tema claro/escuro via JavaScript
- Animação de hover no card usando CSS `transform` e `box-shadow`
- Layout centralizado e responsivo
- Marcação HTML semântica

## Tecnologias

- HTML5
- CSS3 (nesting, transforms, transitions, custom properties)
- JavaScript (DOM manipulation)
- Google Fonts — [Figtree](https://fonts.google.com/specimen/Figtree)

## O que aprendi

- Estruturação semântica com HTML
- Seletores CSS avançados e nesting nativo
- Animações responsivas com `transform: translate3d` e `will-change`
- Manipulação de classes com `classList.toggle` para alternância de temas
